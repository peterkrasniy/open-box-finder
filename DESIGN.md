# Interface design system

Internal generated concepts were inspected after the 08:38 research gate, before application code. Desktop: `/workspace/generated_images/exec-5a0f53dc-4704-4616-b281-19d42f950962.png`. Corrected mobile browse/filter states: `/workspace/generated_images/exec-68e49212-1963-4fa9-a83c-9f880c4eb120.png`. They remain outside public source. The discarded first mobile image invented retailers including excluded Home Depot and is not the specification.

Colors: true white background/surface `#ffffff`; ink `#0b1220`; secondary text `#596579`; subtle cool-gray input/photo background `#f6f8fb`; borders `#dce2eb`; blue action/selected `#0866ef`; comparison red `#c82828`. No gradients or decorative hero. Typography: system sans with Cyrillic fallback, UI 15–16px/1.4, captions 12–13px/1.4, price 26–30px/1.1 bold, main heading 28–34px/1.15. Use tabular price numerals.

Spacing scale: 4/8/12/16/24/32/40px. Radius: controls 10px, imagery/cards 12px, mobile sheet 20px at top corners. Controls have a 44px minimum target, explicit focus ring and deliberate labels. Icons: 24px geometric outline, 2px stroke, rounded caps/joins; search, location pin, sliders, sort, heart/bookmark, arrow, close and open-box. The app's original box mark may be used as a simple faithful icon; no retailer logo recreation.

Desktop: wide header with brand/Deals/Saved/language, broad search and location row, 260–290px permanent filter rail, result/sort toolbar and 2–3 column deal region. Detail uses image adjacent to price/basis/condition/pickup. Saved uses compact rows. Mobile: compact language/brand, selected location row, full-width search, Filters/Sort/category controls, single-column deals, labelled safe-area Deals/Saved navigation; one cancelable filter sheet or vertical detail screen at a time. At 768px keep controls readable and preserve active drafts across presentation changes.

Shared families: primary/secondary/icon buttons, labelled text/decimal inputs, checkbox/radio choices, category controls, source status rows, deal media/card, detail region, saved rows, native dialog. Motion 150–200ms only for state transitions; reduced-motion removes transitions. No entrance choreography. Native dialog owns focus containment; Close/Cancel restores origin focus and scroll.

Allowed primary copy: Open Box Finder; Deals; Saved; EN; РУ; Search deals; Filters; Sort; All; Clear; Retailers; Categories; Fulfillment; Both; Pickup; Shipped; Price (USD); Min price; Max price; Radius (miles); Cancel; Apply; Savings: %; Savings: $; No verified listings yet; Listings appear after a source is verified.; Sources; Awaiting source verification. Required translated/error/availability/freshness/product actions are intentional functional extensions, with exact retailer content retained where licensing requires.

Intentional concept deviations: the desktop card-anatomy specimen and invented figures are never runtime content; no phone bezel/status-bar illustration is implemented; generated concepts are not product-photo assets; shipping wording must distinguish national shipping from local delivery; unavailable integrations appear as truthful source status rather than claimed connections. Real eligible offer data determines populated card contents. The initial truthful empty state is not project completion.
