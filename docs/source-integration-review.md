# Source integration review boundary

This is inactive implementation prepared after the research gate. It does not admit a source, establish public inventory, or prove an unattended job. Parent retains source/security acceptance and independent audit ownership.

`app/api/catalog/route.ts` exposes GET/HEAD. `lib/server/catalog-route.ts` rejects every query string and write method before invoking maintenance; HEAD reads without maintenance. No visitor-supplied URL, records, price, adapter, force parameter, SQL, authorization, cookie or location enters acquisition. The server chooses immutable transport definitions, a recognizable project User-Agent, manual redirects, omitted credentials, strict content types, bounded bytes and eight-second requests. A multi-request admission probe shares one eight-second total network budget.

`lib/server/catalog-store.ts` uses a shared D1 lease, minimum fifteen-minute global cadence and ninety-six attempts per UTC day. Publication must match the active unexpired lease and exactly increment the stored sequence. A disabled/revoked source is rejected both when writing and when reading existing stored payloads. SQL values are bound; database/schema identifiers come only from source. Operational counts contain no shopper profiles or raw retailer error bodies.

`lib/server/pipeline.ts` selects one due, admitted adapter per maintenance cycle. An incomplete response preserves missing prior records; an unconfirmed empty response is a failure. Invalid origins, comparisons and malformed acquisitions preserve the previous records and publish error health. Failure never freshens item observation timestamps. Per-source next-check times preserve the full Retry-After/cache cooldown independently of the shared fifteen-minute limit, so one source cannot impose its long backoff on another. A recorded access denial, redirect or challenge stops automatic attempts until a newer accepted source review, and that review cannot shorten the existing cooldown. Successful complete observations alone advance removal evidence. `lastSnapshotComplete` exposes partial checks; the visible source summary includes checked/attention/disconnected counts. DealNews remains separate complete original editorial content with original links/referral codes, not normalized price or stock.

The configured production source registry remains entirely disabled and `APPROVED_POLICIES` is empty. Following parent source acceptance, `APPROVED_PREFLIGHTS` contains one timestamped A4L private research grant. It can execute once and cannot publish retailer records. Synthetic offers and injected test grants remain confined to tests.

The proposed optional preflight in `lib/server/preflight.ts` uses only two fixed candidates. DealNews performs one licensed RSS read and retains only counts/link origins. Sacramento performs robots + catalog + at most two reviewed exact unit-page reads. A denial, redirect, malformed/unsupported policy, positive crawl-delay, unsafe path or unsupported item representation stops that candidate. Robots compliance is not access/redistribution authorization; this distinction follows [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html). The conservative checker declines unsupported cases. Unit preflight uses exact item-level structured stock/USD cents evidence; a generic Add to Cart, model category, aggregate price or repeated first-page result is insufficient. Every preflight catalog remains explicitly incomplete.

Preflight evidence is private, bounded to 16 KiB per source, and protected by the same lease when stored in `source_preflight`. It contains no full HTML/feed bodies, media, customer data or credentials. It is excluded from public catalog responses and permanent Git catalog history. Each accepted timestamped preflight review is valid for at most twenty-four hours and consumed once before I/O, including a crash or denied attempt. It is not a recurring grant. Durable source/time markers preserve the supplied cooldown after evidence expiry. Executed maintenance clears expired payloads to null; physical cleanup and platform backups still depend on actual execution/retention and are not claimed as verified. Private preflight runs before periodic acquisition so an admitted adapter cannot starve a short-lived review. Private housekeeping failures do not hide a readable public catalog.

### Remaining retest boundary

Syndicated fragments preserve the whole original description/content and use the exact source entry URL as their escaped base, including its path and query. Approved media directories must match the server policy exactly before publication. The fragment CSP allows only those reviewed HTTPS directories; the default is img-src none. The sandbox still excludes script execution and same-origin authority. The isolated browser checks use synthetic permitted media, not a retailer license or production image. All source policies remain empty.

Normalized unit uniqueness uses source/unit/variant/condition/branch tuples, independent of mutable price. Decoder and reconciliation reject aliases; future adapters can use the canonical SHA-256 ID helper. No enabled adapter or real inventory is implied.
